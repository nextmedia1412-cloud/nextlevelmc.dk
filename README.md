# Next Level MC Frontside

Mobiloptimeret frontside til `nextlevelmc.dk`.

## Filer

- `index.html` – selve siden
- `style.css` – design, liquid glass, responsiv styling
- `script.js` – scroll reveal animationer
- `assets/wall.png` – baggrund
- `assets/logo.png` – hovedlogo
- `assets/skull.png` – dekorativt skull-logo
- `CNAME` – GitHub Pages custom domain

## Links

Ret knapperne i `index.html` ved at skifte `href="#"` til de rigtige links.

Eksempel:

```html
<a class="glass-button" href="https://facebook.com/jeres-side" target="_blank" rel="noopener noreferrer">
```

## Deployment

Upload filerne til GitHub-repoet, hvor GitHub Pages er slået til.
